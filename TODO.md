# Implementation Plan — Advanced Features

## Overview
✅ = Already partially exists but needs enhancement
❌ = Needs to be created from scratch

Based on thorough code analysis of the existing codebase.

---

## 1. PDF Viewer for E-Books (react-pdf) — ✅ Enhance

**Current state:** `frontend/components/PDFViewer.tsx` uses an iframe to display PDFs. `react-pdf` and `pdfjs-dist` are already installed but not used.

**Plan:**
- Rewrite PDFViewer.tsx to use `react-pdf`'s `<Document>` and `<Page>` components
- Add page navigation (prev/next, page number input)
- Add zoom controls (fit page, fit width, custom zoom)
- Add full-screen support via CSS
- Keep existing bookmark functionality
- Preserve "Open in new tab" and fallback

## 2. QR Scanner (html5-qrcode + BarcodeDetector) — ✅ Enhance

**Current state:** `frontend/components/QRScanner.tsx` only uses BarcodeDetector API (Chrome-only, limited support). `html5-qrcode` is installed but unused.

**Plan:**
- Rewrite QRScanner.tsx to use `html5-qrcode` as primary scanner
- Keep BarcodeDetector as fallback
- Add better error UI and camera selection
- Improve scan overlay with visual feedback

## 3. QR Display Modal — ❌ Create

**Current state:** No component exists to display QR codes generated by the backend for borrow transactions. The backend generates base64 PNG QR codes in `transaction.service.ts` on approval.

**Plan:**
- Create `frontend/components/QRDisplayModal.tsx` — shows QR code image for book pickup
- Include transaction details (book title, due date, user info)
- Add download/print option for the QR code
- Integrate with transactions page (show QR for ACTIVE transactions)

## 4. Bookmarks / Resume Reading — ✅ Enhance

**Current state:** `PDFViewer.tsx` reads `localStorage.getItem("bookmark:" + bookId)` but does nothing with it. No saving mechanism exists.

**Plan:**
- Add `saveBookmark(bookId, pageNumber)` function using localStorage
- Integrate with react-pdf to auto-save current page on page change
- Show "Resume from page X" prompt on opening an e-book
- Optionally add DB-backed bookmarks via API for cross-device sync

## 5. PWA Configuration — ❌ Create

**Current state:** No PWA support whatsoever.

**Plan:**
- Create `frontend/public/manifest.json` with app name, icons, theme colors
- Add PWA metadata to `frontend/app/layout.tsx` using Next.js metadata API
- Create `frontend/public/icons/` directory with sized PNG icons (192x192, 512x512)
- Add `next.config.ts` headers for service worker
- Add theme-color meta tag and apple-touch-icon

## 6. BookBorrowModal Fix — ✅ Fix

**Current state:** `BookBorrowModal.tsx` uses `await new Promise((r) => setTimeout(r, 800))` as a mock instead of calling the real API.

**Plan:**
- Replace mock timeout with actual `api.createBorrowRequest()` call
- Add proper error handling from API response
- Add loading state and success/error feedback
